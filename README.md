# Nexus

Yetenek ağı uygulaması — Next.js + TypeScript + Tailwind.

## Başlatma

```bash
npm install
npm run dev
```

## Klasör yapısı

```
src/
  app/                 # Next.js app router (layout, page, globals.css)
  components/
    layout/            # Navbar, Footer
    hero/              # Hero, ProfileCard
    discover/          # SectionHeader, Filters, UserCard, SpotlightCard
    ui/                # Avatar, Button, Chip
  data/                # Örnek kullanıcı verisi
  lib/                 # utils
  types/               # ortak tipler
```
